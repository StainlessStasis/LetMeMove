# LetMeMove!
Adds WASD movement to Minecraft Dungeons. This mod was made using the [Minecraft Dungeons Mod Kit](https://github.com/Dokucraft/Dungeons-Mod-Kit). Works on the latest version of the game, despite Blueprint Loader being for 1.9.3.0.

# Installation & Dependencies
First, you'll need to install [Blueprint Loader](https://www.nexusmods.com/minecraftdungeons/mods/111). To install mods:
1) Locate your game's local files. On Steam, right click on it -> `Manage` -> `Browse local files`. If you own the game through the MC launcher then idk, look it up.
2) Navigate to `Dungeons/Content/Paks`.
3) If you don't already have a mods folder, make one in this Paks directory, and name it EXACTLY `~mods` - tilda included!
4) Download the latest release, unzip it, and drop the `.pak` file into that ~mods folder.

# Other Notes
I would suggest using strictly the `Forward Roll` instead of `Directional Roll`, since it feels weird to hold one direction but still roll toward your mouse. Also, the mod is hardcoded to check for WASD - these cannot be rebound. Lastly, this mod also changes the rotation speed of your character to get it to interpolate smoothly. I'm searching for a way to make this value configurable, but until then, let me know if you prefer slower rotation speed, or none at all. Feel free to open an issue or whatever.
