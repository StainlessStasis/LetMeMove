# LetMeMove!
Adds WASD movement to Minecraft Dungeons. This mod was made using the [Minecraft Dungeons Mod Kit](https://github.com/Dokucraft/Dungeons-Mod-Kit) if you wish to build it yourself from source.

# Installation & Dependencies
Along with this mod, you'll need [Blueprint Loader](https://www.nexusmods.com/minecraftdungeons/mods/111). To install mods:
1) Locate your game's local files. On Steam, right click on it -> `Manage` -> `Browse local files`. If you own the game through the MC launcher then idk, look it up.
2) Navigate to `Dungeons/Content/Paks`.
3) If you don't already have a mods folder, make one in this Paks directory, and name it EXACTLY `~mods` - tilda included!
4) Download the latest release, unzip it, and drop the `.pak` file into that ~mods folder.

# Config
Press F8 to open/close the config. Here you can edit the keybinds for movement, and set the turn rate of your character. Multiple actions can be bound to the same key if you wanted to do that for some reason. It won't alert to conflicts or duplicates, so be aware that you'll probably want to double check the game's keybinds before editing LetMeMove's.

# Other Notes
I've made a separate mod for getting rid of left click mouse movement: https://github.com/StainlessStasis/LetMeAttack

I would suggest using strictly the `Forward Roll` instead of `Directional Roll`, since it feels weird to hold one direction but still roll toward your mouse.
